# AMARU MAYU ART JEWELERY - Sistema Web Piloto (POS / IMS / ERP)

Sistema de gestión web para el control de inventarios multi-sede, punto de venta (POS) y liquidación automatizada de comisiones para la empresa de joyería de lujo **AMARU MAYU ART JEWELERY** (Cusco, Perú).

---

## 📌 Alcance del Sistema (Piloto)

- **Catálogo Maestro & SKU Unificado:** Generación automatizada de códigos únicos por producto y artesano.
- **Control de Inventarios Multi-Sede:** Gestión de stock por sedes (Uchuyo - 21 vitrinas, Hotel Pacha y Hotel José Antonio).
- **Movimientos & Traspasos:** Registro de ingresos por proveedor (artesanos), traspasos inter-tienda con confirmación en dos pasos y ajustes de merma.
- **Punto de Venta (POS):** Sesiones de caja con apertura/cierre, arqueo diario por vitrina y cobro mediante pagos mixtos (Efectivo, Tarjeta, Yape/Plin, Transferencia).
- **Gestión de Comisiones:** Liquidación automatizada basada en montos congelados por venta.
- **Consulta Global:** Vista unificada de stock multi-sede para vendedores en tiempo real.

---

## 🛠️ Stack Tecnológico

- **Backend:** Laravel 11+ (PHP)
- **Frontend:** Blade + TailwindCSS (Diseño Responsive)
- **Base de Datos:** Supabase / PostgreSQL
- **Control de Versiones:** Git & GitHub
